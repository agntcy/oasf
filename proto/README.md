# OASF

This repository contains the protocol definitions and language stubs for the
[Open Agentic Schema Framework](https://schema.oasf.outshift.com).

## Compatibility Matrix

```markdown
| Schema Version | Proto Version  |
| -------------- | -------------- |
| v0.7.0         | types/v1alpha1 |
| v0.8.0         | types/v1alpha2 |
| v1.0.0         | types/v1       |
| v1.1.0         | types/v1       |
```

The schema versions that each [oasf-server](https://github.com/agntcy/oasf-server)
release serves are listed in its
[`schema-versions.json`](https://github.com/agntcy/oasf-server/blob/main/schema-versions.json).
